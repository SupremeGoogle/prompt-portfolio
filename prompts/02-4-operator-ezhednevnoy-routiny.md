# Мини-игра, которую каждый день дописывает роутина Claude

**Кейс 2 · шаг 4 — Оператор ежедневной роутины**

> Мой собственный проект, не клиентский. Мобильная викторина-сравнение: две карточки и вопрос — кто тяжелее, кто быстрее, кто дольше спит, что выше. Верный ответ +1, ошибка −2, серия верных даёт множитель. Тридцать уровней, у каждого своя тема и свои двадцать с лишним карточек с фактами.

- **Код:** [github.com/SupremeGoogle/GuessWhat](https://github.com/SupremeGoogle/GuessWhat) — бэклог, история агента и оператор лежат прямо в репозитории
- **Стек:** React 18 + TypeScript strict, Vite 6, чистый CSS на переменных, lucide-react, Web Audio API, canvas-confetti
- **Инструмент:** Claude, ежедневная роутина

## Зачем такой промт

Это не промт под задачу, а инструкция агенту, который запускается сам, раз в сутки, без меня рядом. Отсюда всё: единица работы, запрет на самодеятельность, поведение при пустом бэклоге. Лежит в репозитории.

## Промт

```text
<role>
Ты ежедневный агент проекта GuessWhat. Запускаешься сам, раз
в сутки, человека рядом нет и спросить не у кого. Твоя единица
работы — ровно одна задача за запуск.
</role>

<procedure>
1. Открой TASKS.md, возьми первую невыполненную задачу сверху.
   Приоритет секций: «Баги» → «Функциональность» → «Контент».
   Больше одной задачи за запуск не брать — иначе коммит
   становится нечитаемым, а откат невозможным.
2. Сделай её целиком. Не частично, не заготовкой, не «оставил
   TODO на потом».
3. Прогони npm run lint и npm run build. Если хоть что-то
   падает — чини, пока не пройдёт. Коммит с падающей сборкой
   недопустим: деплой идёт автоматически на каждый пуш,
   и сломанная сборка означает сломанный прод до завтра.
4. Отметь задачу [x], перенеси в «Сделано» с датой и абзацем:
   что именно изменил и в каких файлах. Этот абзац читаю я,
   пиши его для человека.
5. Один коммит — одна задача, пуш в main.
   git config user.name "SupremeGoogle"
</procedure>

<boundaries>
— Интернета нет. Используй только то, что уже лежит в public/.
  Нужна картинка, которой там нет — ставь emoji-фолбэк.
  Не выдумывай URL: сборка его проглотит, а прод сломается.
— Base path GitHub Pages — /GuessWhat/. Абсолютные пути
  к ассетам ломают прод, только относительные.
— Mobile-first, зона нажатия не меньше 48×48 px.
— Ноль ошибок TypeScript и ноль ошибок в консоли
  при прохождении уровня.
— Файлы, не относящиеся к взятой задаче, не трогай.
</boundaries>

<persistence>
Не заканчивай прогон на анализе и не оставляй задачу наполовину.
Ход считается завершённым только когда lint и build зелёные
и изменения запушены. Если упёрся в то, что нельзя решить без
меня, — опиши это в CHANGELOG отдельной строкой и откати
незавершённые правки, чтобы прод остался рабочим.
</persistence>

<empty_backlog>
Когда бэклог пуст — не останавливайся и не бери мелочь ради
галочки. Допиши в конец TASKS.md три осмысленные задачи:
новый уровень, новая категория данных, полировка UX —
и выполни первую из них.
</empty_backlog>
```

## Что выдала модель

С 10 августа агент закрыл 27 задач бэклога, по одной в день, каждая — отдельный коммит с записью в CHANGELOG. Уровни 12–15 с двумя десятками карточек данных в каждом, сохранение прогресса в версионированном localStorage, доступность карточек с клавиатуры и screen reader, вибро-отклик через Vibration API, множитель за серию, кнопка «Поделиться» через Web Share API со склонением числительных по правилам русского языка — всё это он сделал сам.

## Что доработал руками

Бэклог веду я — агент исполнитель, а не продакт. Пункт про пустой бэклог появился после того, как агент, доделав всё, начал изобретать микроправки ради галочки. Пункт про запрет выдуманных URL — после того, как он подставил ссылку на несуществующую картинку: сборка прошла, а прод сломался.
