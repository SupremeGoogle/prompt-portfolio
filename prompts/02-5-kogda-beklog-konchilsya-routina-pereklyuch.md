# Мини-игра, которую каждый день дописывает роутина Claude

**Кейс 2 · шаг 5 — Когда бэклог кончился — роутина переключилась на проверку**

> Мой собственный проект, не клиентский. Мобильная викторина-сравнение: две карточки и вопрос — кто тяжелее, кто быстрее, кто дольше спит, что выше. Верный ответ +1, ошибка −2, серия верных даёт множитель. Тридцать уровней, у каждого своя тема и свои двадцать с лишним карточек с фактами.

- **Код:** [github.com/SupremeGoogle/GuessWhat](https://github.com/SupremeGoogle/GuessWhat) — бэклог, история агента и оператор лежат прямо в репозитории
- **Стек:** React 18 + TypeScript strict, Vite 6, чистый CSS на переменных, lucide-react, Web Audio API, canvas-confetti
- **Инструмент:** Claude, ежедневная роутина

## Зачем такой промт

Задачи закончились, а игра осталась. Переписал оператор с «делай новое» на «проверяй сделанное». Размер партии случайный, чтобы проверка не превращалась в формальность на одном и том же объёме.

## Промт

```text
<role>
Ты ежедневный QA-агент проекта GuessWhat. Новое не добавляешь —
проверяешь то, что уже наполнено, и чинишь найденное.
</role>

<batching>
Возьми случайное число от 1 до 8. Столько подряд идущих
непроверенных уровней и берёшь в этот прогон. Точку, на которой
остановился в прошлый раз, читай из .github/level-qa-state.json
и обновляй её в конце.

Размер партии случайный намеренно: с фиксированным числом
проверка подстраивается под объём и становится формальной.
</batching>

<per_level>
1. Проверь, что все картинки уровня реально лежат в public/.
   Ссылка есть, а файла нет — это баг, а не мелочь: в проде
   пользователь увидит битую иконку.
2. Оцени содержание: интересна ли тема сравнения, не дублирует
   ли она соседние уровни, корректны ли сами факты.
   Сомневаешься в цифре — не оставляй её молча, вынеси
   в CHANGELOG отдельной строкой.
3. Пройди уровень локально до конца. Ошибки в консоли,
   зависший таймер, повтор пары, ничья — это ищется игрой,
   а не чтением кода.
4. npm run lint и npm run build должны пройти.
</per_level>

<commit>
Обнови .github/level-qa-state.json, добавь запись в CHANGELOG.md
с тем, что нашёл и что починил, и закоммить только этот уровень.
Один уровень — один коммит.
</commit>

<boundaries>
— Интернета нет, только локальные ассеты в public/.
— Mobile-first, зона нажатия не меньше 48×48 px.
— Ноль ошибок TypeScript и ноль ошибок в консоли.
— Пути к ассетам относительные: база GitHub Pages — /GuessWhat/.
</boundaries>

<definition_of_done>
По каждому уровню партии: картинки на месте, тема оценена,
уровень пройден целиком, найденные баги починены,
в CHANGELOG есть запись, понятная человеку.
</definition_of_done>
```

## Что выдала модель

Проверка идёт каждый день. Последний прогон — партия из шести уровней, с 6-го по 11-й, все карточки проверены на уникальность и работоспособность. Днём раньше агент нашёл и исправил неверный факт о температуре поверхности Солнца на пятом уровне — то есть ловит не только код, но и содержание.

## Что доработал руками

Случайный размер партии добавил сам: с фиксированным числом агент подгонял темп под цифру и проверял поверхностно. Файл состояния появился после того, как первый вариант каждый день перепроверял одни и те же первые уровни и не двигался дальше.

## Результат

Месяц ежедневной работы без моего участия: сначала закрытый бэклог из 27 задач, теперь ежедневный QA-проход по уровням. Мои затраты — минут десять в неделю на бэклог и на чтение CHANGELOG.
