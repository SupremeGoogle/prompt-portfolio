# Мини-игра, которую каждый день дописывает роутина Claude

**Кейс 2 · шаг 3 — Точечный разбор багов**

- **Код:** [github.com/SupremeGoogle/GuessWhat](https://github.com/SupremeGoogle/GuessWhat) — бэклог, история агента и оператор лежат прямо в репозитории
- **Стек:** React 18 + TypeScript strict, Vite 6, чистый CSS на переменных, lucide-react, Web Audio API, canvas-confetti
- **Инструмент:** Claude, ежедневная роутина

## Промт

```text
<task>
Три бага. Чини по одному, после каждого — отдельный коммит.
</task>

<bugs>
<bug id="1" file="src/components/Level1Game.tsx">
Утечка таймера. Таймер ставится в useEffect, но при рестарте
раунда старый не снимается — после нескольких заходов счёт
начинает скакать, потому что тикает сразу несколько таймеров.
Держи id в useRef, снимай перед постановкой нового
и при размонтировании.
</bug>

<bug id="2" file="src/App.tsx">
Повторы пар. generateNewPair берёт случайную пару каждый раз,
поэтому внутри одного раунда одна и та же пара выпадает дважды.
Собери очередь пар заранее, перемешай Фишером-Йетсом,
пересоздавай при рестарте.
</bug>

<bug id="3" file="src/App.tsx">
Ничья по весу. Если веса совпали, любой выбор засчитывается
как ошибка. Подбирай второго кандидата с другим значением.
</bug>
</bugs>

<method>
По каждому багу сначала процитируй строку, в которой он живёт,
потом покажи диff. Цитата — это проверка, что ты нашёл то самое
место, а не похожее.
</method>

<scope>
Меняй ровно те строки, которые относятся к описанному дефекту.
Имена, типы и комментарии в соседнем коде оставь как есть —
их правки смешаются с исправлением, и при откате придётся
разбирать, что было починкой, а что вкусовщиной.
</scope>

<examples>

  const id = setInterval(tick, 1000)   // Level1Game.tsx:42

</example>

<example type="плохо">

в отдельный хук и добавил типы.
</example>
</examples>
```
