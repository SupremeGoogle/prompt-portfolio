# Мини-игра, которую каждый день дописывает агент

**Кейс 2 · шаг 4 — Оператор для ежедневного агента**

> Мой собственный проект, не клиентский. Мобильная викторина-сравнение: игроку показывают две карточки и задают вопрос — кто тяжелее, кто быстрее, кто дольше спит, что выше. Верный ответ **+1**, ошибка **−2**, серия верных даёт множитель. Тридцать уровней, у каждого своя тема сравнения и свои двадцать с лишним карточек с фактами.

- **Код:** [github.com/SupremeGoogle/GuessWhat](https://github.com/SupremeGoogle/GuessWhat) — бэклог, история агента и оператор лежат прямо в репозитории
- **Стек:** React 18 + TypeScript strict, Vite 6, Web Audio API, canvas-confetti
- **Инструмент:** Claude, ежедневная роутина. Я задавал механику, ограничения и разбирал баги.

## Зачем такой промт

Это уже не промт под задачу, а инструкция агенту, который запускается сам, раз в сутки, без меня рядом. Лежит в репозитории: `.github/daily-task.md`.

## Промт

```text
Ты ежедневный агент проекта GuessWhat. Запускаешься сам,
раз в сутки, человека рядом нет. Закрываешь ровно одну задачу.

ПОРЯДОК:
1. Открой TASKS.md, возьми первую невыполненную задачу
   сверху. Приоритет секций: «Баги» → «Функциональность»
   → «Контент». Больше одной задачи за запуск не брать.
2. Сделай её целиком. Не частично, не заготовкой.
3. Прогони npm run lint и npm run build. Если хоть что-то
   падает — чини, пока не пройдёт. Коммит с падающей
   сборкой недопустим.
4. Отметь задачу [x], перенеси в «Сделано» с датой
   и абзацем: что именно изменил и в каких файлах.
5. Один коммит — одна задача, пуш в main.
   git config user.name "SupremeGoogle"

ГРАНИЦЫ:
— Интернета нет. Только то, что уже лежит в public/.
  Нужна картинка, которой нет — ставь emoji-фолбэк,
  не выдумывай URL.
— Base path GitHub Pages — /GuessWhat/. Абсолютные пути
  к ассетам ломают прод, только относительные.
— Mobile-first, зона нажатия не меньше 48×48 px.
— Ноль ошибок TypeScript и ноль ошибок в консоли
  при прохождении уровня.
— Файлы, не относящиеся к взятой задаче, не трогай.

КОГДА БЭКЛОГ ПУСТ:
Не останавливайся и не бери мелочь ради галочки.
Допиши в конец TASKS.md три осмысленные задачи —
новый уровень, новая категория данных, полировка UX —
и выполни первую из них.
```

## Что выдала модель

С 10 августа агент закрыл 27 задач бэклога, по одной в день, каждая — отдельный коммит с записью в CHANGELOG. Уровни 12–15 с двумя десятками карточек данных в каждом, сохранение прогресса, доступность карточек с клавиатуры, вибро-отклик, множитель за серию, кнопка «Поделиться» через Web Share API — всё это он сделал сам.

## Что доработал руками

Бэклог веду я — агент исполнитель, а не продакт. Пункт про пустой бэклог появился после того, как агент, доделав всё, начал изобретать микроправки ради галочки. Пункт про запрет выдуманных URL — после того, как он подставил ссылку на несуществующую картинку: сборка прошла, а прод сломался.
