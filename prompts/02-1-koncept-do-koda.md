# Мини-игра, которую каждый день дописывает агент

**Кейс 2 · шаг 1 — Концепт до кода**

> Мой собственный проект, не клиентский. Мобильная викторина-сравнение: игроку показывают две карточки и задают вопрос — кто тяжелее, кто быстрее, кто дольше спит, что выше. Верный ответ **+1**, ошибка **−2**, серия верных даёт множитель. Тридцать уровней, у каждого своя тема сравнения и свои двадцать с лишним карточек с фактами.

- **Код:** [github.com/SupremeGoogle/GuessWhat](https://github.com/SupremeGoogle/GuessWhat) — бэклог, история агента и оператор лежат прямо в репозитории
- **Стек:** React 18 + TypeScript strict, Vite 6, Web Audio API, canvas-confetti
- **Инструмент:** Claude, ежедневная роутина. Я задавал механику, ограничения и разбирал баги.

## Зачем такой промт

Первый промт вообще ничего не кодит. Задача — получить три разные механики и выбрать одну, а не чинить потом ту, что модель придумала между делом.

## Промт

```text
Ты продуктовый дизайнер мобильных казуальных игр.

Задача: придумать механику для веб-викторины, которую человек
открывает с телефона и играет 2–3 минуты, без регистрации,
без обучения и без объяснений.

Вводные:
— аудитория: подростки 10–16 лет и их родители;
— заход только по прямой ссылке, никаких сторов;
— контент должен масштабироваться: я хочу добавлять новые
  темы, не переписывая игру.

Дай 3 концепта. По каждому:
1. Механика в одном предложении.
2. Что игрок делает в первые 5 секунд.
3. Почему он откроет игру второй раз.
4. Как устроены данные, чтобы новая тема = один новый файл.
5. Слабое место концепта — честно, а не для галочки.

Ничего не кодируй. Только концепты, таблицей.
```

## Что выдала модель

Три механики: сравнение двух объектов, угадывание по нарастающим подсказкам и «правда или миф». Первая выиграла по пункту 4 — данные ложатся в плоский массив, новая тема действительно один файл.

## Что доработал руками

Модель предложила +1 за верный ответ и 0 за неверный. При такой экономике выгодно тыкать наугад, риска нет. Поставил −2 за ошибку. Позже добавился множитель за серию с шагом 3, и пороги звёзд пришлось пересчитать с 4/8 на 10/20 — старые брались слишком легко.
